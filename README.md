# Quiz By OOPS Concept

A simple and interactive Quiz Application developed using **Python** and **Object-Oriented Programming (OOP)** concepts.  
This project demonstrates the practical implementation of OOP principles such as classes, objects, encapsulation, inheritance, polymorphism, and abstraction in a quiz management system.

---

## 📌 Features

- Multiple-choice quiz questions
- Score calculation system
- Interactive console-based interface
- OOP-based project structure
- Easy to add or modify questions
- Clean and reusable Python code

---

## 🛠️ Technologies Used

- **Python**
- Object-Oriented Programming (OOP)
- Console Application

## 🚀 OOP Concepts Used

### 1. Class and Object
Classes are used to create quiz entities like questions, users, and quiz management objects.

### 2. Encapsulation
Data and methods are organized together inside classes to improve security and maintainability.

### 3. Inheritance
Child classes inherit properties and methods from parent classes.

### 4. Polymorphism
Methods can behave differently depending on the object implementation.

### 5. Abstraction
Complex logic is hidden from the user and only essential functionalities are exposed.
